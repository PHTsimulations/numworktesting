Cloud build workflow (no Node/npm installation locally):
1. Upload the contents of this package to your GitHub repository root, keeping .github/workflows/build.yml.
2. In the repository, select Actions. Enable workflows if prompted.
3. Open Build Aero Database NWA; choose Run workflow if it hasn't run automatically.
4. When green/successful, open the run and download artifact AeroDatabase-NWA.
5. Extract it to get AeroDatabase.nwa, then upload at https://my.numworks.com/apps.
